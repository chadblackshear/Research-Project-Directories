# Research-Project-Directories

This is a collection of suggested default collaborative directories that will house various files commonly encountered during a biomedical research project. Documentation describing project aspects have been included (e.g. metadata compendium shell, scientific review overviews, proposal templates, etc.).

This release contains all of the folders, so you can drop this folder into a shared workspace (e.g. Dropbox, OneDrive, Google Drive, etc.), and then add all of your data, code, and results to the corresponding subfolders.

# Instructions

- Go to the Releases page and download the latest collab.zip release
- Unzip the file and place the folder in your desired directory
- Drop all of your files into their corresponding subfolder
- Start having fun with your collaborators
